# Данные для запуска пилота

Пароли от Google, Telegram или сервера передавать не нужно.

## 1. Telegram

1. Открыть в Telegram официальный `@BotFather`.
2. Отправить `/newbot`.
3. Указать отображаемое имя и username, который заканчивается на `bot`.
4. Сохранить выданный token в файл:

   `C:\Users\ibogdanovskaia\Desktop\Яна\Мастер CFO\Сервер на beget\telegram_bot_token.txt`

В файле должен быть только token. В чат его копировать не нужно.

5. Открыть созданного бота и отправить ему `/start`. Это позволит безопасно определить Telegram ID администратора.

## 2. Google Calendar

1. Открыть Google Cloud Console под тем Google-аккаунтом, где находится календарь.
2. Создать проект, например `Telegram Calendar Bot`.
3. Включить `Google Calendar API`.
4. Настроить OAuth consent screen. Для закрытого пилота можно оставить режим Testing и добавить свой email в Test users.
5. Создать OAuth Client ID типа `Desktop app`.
6. Скачать JSON и сохранить как:

   `C:\Users\ibogdanovskaia\Desktop\Яна\Мастер CFO\Сервер на beget\google_credentials.json`

После появления обоих файлов достаточно написать в чате: «Готово».
