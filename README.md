# Telegram Calendar Bot

Лёгкий Telegram-бот для запроса и согласования встреч в одном Google Calendar.

## Архитектура

- Python 3.12;
- aiogram 3, Telegram long polling;
- лёгкий шлюз Google Apps Script к личному Google Calendar;
- SQLite в WAL-режиме;
- systemd для запуска и автоперезапуска;
- JSONL-логи и отдельный аудит в базе.

## Реализованный функционал

- выбор свободного слота и отправка заявки владельцу;
- настраиваемое окно записи пользователей и выбор слотов по частям дня;
- согласование или отклонение в Telegram;
- создание Google-события и приглашение гостя;
- изменение и отмена заявки до согласования;
- явное отображение завершившегося резерва слота;
- справка и политика конфиденциальности;
- встроенные настройки срока записи, горизонта, резерва, длительностей и шага слотов;
- закрытые даты и временная остановка новой записи;
- версионируемые SQLite-миграции и проверяемая копия перед обновлением;
- альтернативные слоты и повторное подтверждение пользователя;
- запросы переноса и отмены согласованных встреч;
- изменение и удаление событий Google Calendar;
- ручные встречи администратора с гостем или без гостя;
- подтверждаемые пересечения и неблокирующие события.
- ежедневные, еженедельные и ежемесячные серии и управление отдельными повторениями;
- настраиваемые Telegram-напоминания и периодическая сверка с Google;
- календарный выбор даты, компактный ввод времени и редактирование черновика перед созданием;
- базовая статистика по периодам;
- 12-месячный retention и два подтверждаемых сценария удаления данных;
- ограничение частоты запросов, ротация логов, 30-дневные backup и автоматический health-check.

## Необходимые секреты

Секреты не хранятся в Git. Для запуска нужны:

- Telegram Bot Token;
- Telegram ID администратора;
- OAuth Desktop Client JSON из Google Cloud;
- полученный после разрешения Google token.

## Локальная проверка

```powershell
python -m unittest discover -s tests -v
python -m compileall app scripts tests
```

## Запуск

После задания переменных и настройки календарного шлюза:

```bash
python -m app.main
```

Производственный запуск выполняется через файлы из `deploy/`.

Рабочие Telegram/Google-токены, URL шлюза, общие секреты и база данных исключены из Git.
