# Релиз D — регрессионная и приёмочная матрица

## Автоматическая регрессия A–C

- [ ] Главное меню пользователя содержит прежние `Записаться`, `Мои заявки`, `Помощь`, `Конфиденциальность` в прежнем порядке.
- [ ] Главное меню администратора дополнительно содержит прежние заявки, изменения, ручную встречу, серии и настройки в прежнем порядке.
- [ ] Создание, редактирование и отмена pending-заявки работают.
- [ ] Согласование и отклонение работают.
- [ ] Альтернативы, перенос и отмена согласованной встречи работают.
- [ ] Ручная встреча и подтверждённое пересечение работают.
- [ ] Серия, одно повторение и вся серия работают.
- [ ] Напоминания и Google-сверка работают.
- [ ] Календарь даты, время без двоеточия и редактор финального черновика работают.

## UAT релиза D

- [ ] В `Настройки → Статистика` доступны пять периодов и показываются только агрегированные числа.
- [ ] Обычный пользователь не может открыть статистику поддельной кнопкой.
- [ ] В `Конфиденциальность → Управление моими данными` доступны два варианта.
- [ ] Кнопка `Не удалять` прекращает процедуру без изменения данных.
- [ ] Финальное выполнение невозможно без двух последовательных подтверждений.
- [ ] Вариант отмены удаляет будущие Google-события и обезличивает локальную историю.
- [ ] При ошибке Google локальные данные не получают ложный статус завершённого удаления.
- [ ] Вариант сохранения не удаляет будущие Google-события и минимизирует локальные данные.
- [ ] После последней сохранённой встречи retention завершает обезличивание.
- [ ] История старше 12 месяцев обезличивается, свежие данные не меняются.
- [ ] Backup старше 30 дней удаляется, свежий backup проходит SQLite integrity check.
- [ ] Восстановленная во временный файл база совпадает по контрольным счётчикам.
- [ ] Health-check проверяет базу, backup, диск, токен и Apps Script.
- [ ] При искусственной ошибке health-check возвращает ненулевой код и формирует alert без секретов.
- [ ] Сервис после выпуска не перезапускается циклически, память ниже 220 МБ, свободно не менее 2 ГБ диска.

Удаление проверяется только на отдельном тестовом Telegram-пользователе. Рабочие данные владельца для UAT не используются.
